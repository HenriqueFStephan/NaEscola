# ADR 003 — Official skills and proposed sequence

## Status

Accepted.

## Decision

Each topic carries the official skill statement, code, official year span, and source locator. `sequenceKind` is `naescola-proposed`. The order follows the source document's line order and is labeled as a NaEscola choice.

Prerequisite links have a kind:

- `conceptual` — a dependency proposed by NaEscola, checked against the skill text.
- `cross-subject` — a proposed link across components.
- `same-official-code-previous-year` — the same official code also applies to the previous grade in this release.

None of these kinds is stored as a BNCC-mandated lesson order.

Ensino Religioso is included and flagged as matrícula facultativa, citing CF/1988, art. 210, §1º by identifier. Língua Inglesa is omitted, with an explicit note, before 6º ano. Computação from Parecer CNE/CEB nº 2/2022 is included and labeled as a complement, not as a 2018 BNCC skill.

## Consequences

Coverage counts topics that have a published lesson. A repeated multi-year code is one placement per grade, not a new official skill.

The same distinction is extended to the rest of basic education in ADR 004. Grades 3–6 keep their skill texts, order, and existing prerequisite edges.
