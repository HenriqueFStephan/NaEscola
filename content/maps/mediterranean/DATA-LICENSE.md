# Mediterranean map data

The GeoJSON files in this directory are a filtered, coordinate-rounded subset of [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps) at commit `da7a4b735ecef70aebdc9c73e409d8a2500d50f3`.

The upstream repository distributes a GNU General Public License v3.0 text. That license is copied in `GPL-3.0.txt` and applies to these GeoJSON files. The rest of the NaEscola application is not declared to be GPL. The repository owner has not chosen a project-wide license.

Every included feature keeps the upstream `NAME`, `SUBJECTO`, `PARTOF`, and `BORDERPRECISION` values. In the snapshots used here, `BORDERPRECISION` is 1, which the upstream project describes as approximate. NaEscola does not add borders between these years and does not present the lines as surveyed frontiers.

Labels that NaEscola translates are listed in `glosses.json`. Unlisted names stay in the dataset's language.
